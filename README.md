# designwandergrid

A minimal 3×3 photo grid maker for the Design Wander event. Attendees turn their nine photo discoveries into a full-frame Instagram Story mood board (1080 × 1920 PNG).

- Upload up to nine photos at once (JPG, PNG, HEIC) or tap a cell to fill it
- Drag to reposition, pinch / scroll / slider to zoom; replace, swap, remove
- Download a clean 1080 × 1920 PNG — on phones it opens the share sheet so you can save to Photos
- Everything runs in the browser: no account, no backend, photos never leave the device

## Run

It's a single static file. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Vercel, Netlify). Phones need it served over HTTPS for sharing to work.
